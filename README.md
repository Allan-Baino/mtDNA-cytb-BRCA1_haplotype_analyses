
## Layout details steps to reproduce analyses in work submitted for publication "Genetic variation in mitochondrial and nuclear DNA reveals cryptic taxonomic diversity in African giant pouched rats (Cricetomys spp.; Rodentia: Nesomyidae)".

## Brief overview: 
mtDNA-cytb and nDNA-BRCA1 genes from African giant pouched rat DNA were partially amplified and sequenced by the Sanger method to generate ~ 756 bp (cytb) and ~ 900 bp (BRCA1) DNA sequences. These sequence data were wrangled with GUI tools such as Geneious, DnaSP, QGIS and command-line (CLI) tools such as MRBayes to answer haplotype-based research questions. It is recommended that users familiarise with mentioned GUI and CLI tools. Access to a computing cluster is recommended although all analyses can conveniently run on a computer laptop with a single CPU. 

## Data description & availability: 
74 Cytb and 52 BRCA1 unaligned sequences are available on NCBI/GenBank with accession numbers PZ833940 - PZ834013 and XXXX. In the .txt file, a set of instructions to wrangle the data are available. Users are welcome to try analyses with different software especially where licensing is limiting (e.g. Geneious). It is anticipated differences in software algorithm(s) will not significantly alter biological conclusions (users will likely arrive at the same conclusions within published article).
